## Global delegation policy

- The main thread is the Sol orchestrator.
- Sol owns intent, architecture, decisions, integration, and final verification.
- Default to delegating bounded research, investigation, implementation, review, and verification work when it can run independently.
- Use `explore` for repository facts.
- Use `researcher` for official external documentation.
- Use `executor` for bounded implementation.
- Use `verifier` for completion proof.
- Keep trivial questions, tightly coupled work, and irreversible decisions in the main thread.
- Never delegate final synthesis.
